# Corporate Pi profile

Keep replies concise. Follow the target repository's rules, verify required work, and use Todo for substantive multi-step tasks. Prefer the smallest correct implementation (Ponytail). Do not copy confidential work data, credentials or corporate source into personal services without approval.

Use pi-subagents' built-in scout, researcher, evidence-auditor, worker, reviewer, oracle and delegate roles when useful. The parent owns the full objective; children do not recursively delegate. At most two child runs are configured, but VDI capacity may require fewer. Wait for native child-completion notifications rather than polling. Do not assume a role's read-only intent is a sandbox guarantee.

This profile declares no MCP servers; review any existing servers retained during installation. Add only corporate-approved servers and check tool approvals. Use web access only where corporate policy permits it. Billion Context Pi handles compaction; its delegation is disabled in the accompanying ACP configuration. Do not install Designer, Observer, Antigravity or unrelated packages from the personal profile.

Goal X is the only goal extension in this profile. `/goal <idea>` requires draft confirmation; `/goal-direct <objective>` starts an agreed goal. Keep Goal X evidence and Todo tasks aligned. Claim completion with `update_goal` only after the full objective and checks are verified. Respect pauses, limits, failures, and explicit cancellation; do not call legacy `goal_complete` or `goal_wait` tools.
